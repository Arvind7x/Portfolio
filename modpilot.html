Meet ModPilot.

A Discord mod-helper bot I built and run: support tickets in threads, instant FAQ answers, raid cards, and AI summaries of long ticket threads — so mods answer faster and chats stay clean.

Free for communities I mod·by LEABERT →

Four commands, zero learning curve.

Mods already know how to use it — it's just slash commands.

/faq

Instant answers

Bridge steps, faucet links, wallet safety, rules — saved answers posted in one tap. Cuts repeat questions.

/ticket

Support threads

Opens a private thread per problem, tags the user, reminds them what info to add. A real queue instead of chat chaos.

/raid

Raid cards

Target + time + rules in one clean post. Keeps raids fast and kind.

/summarize

AI thread summaries

Reads a long ticket thread and returns problem → likely fix → suggested mod reply. Runs on cheap, fast models.

Built to stay up.

Hosted 24/7 with uptime monitoring. No setup for mods — invite, grant three permissions, done.

Always on

Cloud-hosted with automatic restarts and round-the-clock health pings.

AI with an off-switch

If the AI backend ever sleeps, the bot says so and keeps working — tickets and FAQs never depend on it.

Made by a mod

Designed from real ticket queues I worked — not a generic template bot.
